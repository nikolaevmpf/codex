Зайти в ЛК https://lk.astra.ru Раздел Активация, подраздел Локальный сервер активации лицензий (ЛСАЛ)

Создать подписку на ЛСАЛ 
Создать подписку для клиента появится надпись сказать манифест

Получить манифест для ЛСАЛ из ЛК на физический сервер ЛСАЛ:
```
astra-lsla get-activation-manifest --username <логин от ЛК Астры> --passowrd <Пароль от ЛК Астры>
```

Скачать пакет astra-lsal(https://dl.astralinux.ru/ui/native/astra-lsla/pool/1.8_x86-64/) на сервер ЛСАЛ

На ПК, который является ЛСАЛ, скачается файл в папку /var/opt/astra-lsla/manifest/

```
astra-lsla activate --server-name <Имя машины, которая будет Сервером активации лицензий>
```
Задать логин и пароль на сервере ЛСАЛ
```
astra-lsla set-credentials

далее указать логин и пароль
```

Скачать манифесты на Сервер ЛСАЛ
```
astra-lsla get-manifest --pool-id <ID подписки>
```
# Активация клиента

Проверить статус активации на клиенте:
```
astra-subscription status
```
Может потребоваться до установить пакеты:
astra-subscription-desktop
astra-subscription-server
astra-subscription-embedded
astra-subscription-mobile

На клиенте в файле /etc/astra-subscription/common.yaml

```
baseurl: "https://<ИМЯ ПК с ЛСАЛ>"
в строке server.prefix удалить символ "/" в конце строки
insecure: false
port: 8000
```

далее выполнять активацию через 
```
astra-subscription register
```
 
Ввести логин  и пароль введенные для Сервер ЛСАЛ
далее покажет сообщение 
```
Пользователь superadmin член организации 197800024, 197800024
Появится запрос организации ввести 197800024
Выдаст статус регистрации зарегистрирован и покажет ID клиента
```

Активация клиента 
```
astra-subscription attach --pool-id <ID подписки>
```

После выполнения команды появится сообщение:
```
Статус прикрепления: Прикреплено
Активированные продукты: 1040101008
```
