# fdisk: разметка диска

```bash
lsblk -o NAME,SIZE,MODEL,FSTYPE,MOUNTPOINTS
sudo fdisk /dev/sdX  # Заменить устройством, не разделом
```

> [!warning] Сохранение разметки
> Команда `w` записывает изменения на диск. Проверьте выбранное устройство и резервную копию данных.

| Команда | Действие |
| --- | --- |
| `m` | Справка |
| `p` | Показать таблицу разделов |
| `F` | Показать свободное место |
| `n` | Создать раздел |
| `d` | Удалить раздел |
| `t` | Изменить тип раздела |
| `l` | Список типов |
| `i` | Информация о разделе |
| `g` | Создать пустую GPT |
| `o` | Создать пустую MBR |
| `a` | Переключить boot-флаг MBR |
| `O` | Сохранить разметку в файл сценария |
| `I` | Загрузить разметку из сценария |
| `w` | Записать изменения и выйти |
| `q` | Выйти без сохранения |

Для UEFI обычно используют GPT с типами **EFI System**, **Linux swap**, **Linux filesystem**. Номера типов выбирайте по списку `l`: они зависят от вида таблицы.

Форматирование разделов выполняется отдельно; см. [[Linux/Arch/Install|Установка Arch Linux]].
