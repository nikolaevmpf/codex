# NixOS: изменение конфигурации

[[Содержание|Главное оглавление]] · [[Linux/NixOS/Обзор|NixOS]]

Для системы, установленной по заметке [[Linux/NixOS/Установка|NixOS: установка UEFI с disko]]. Источник конфигурации — `/etc/nixos`, имя конфигурации — `nixos`.

## Перед изменениями

```bash
cd /etc/nixos
ls
sudo nano hosts/nixos/configuration.nix
```

Сохраните `flake.nix`, `flake.lock`, `disko.nix` и `hardware-configuration.nix`. Не подставляйте UUID другой машины и не запускайте повторно форматирование disko.

## Пример дополнительных настроек

Добавьте в существующий блок `{ ... }`, не создавая дубликатов опций:

```nix
# Flakes и современный интерфейс Nix
nix.settings.experimental-features = [ "nix-command" "flakes" ];

# Программы — объединить с существующим списком
# environment.systemPackages = with pkgs; [ vim git curl wget htop ];

# SSH включать только при необходимости
services.openssh.enable = true;
networking.firewall.allowedTCPPorts = [ 22 ];
```

`system.stateVersion` сохраняйте от первой установки: это версия совместимости данных, а не переключатель обновления.

## Сборка и применение

```bash
cd /etc/nixos
sudo nixos-rebuild build --flake .#nixos
sudo nixos-rebuild test --flake .#nixos    # Применить до перезагрузки
sudo nixos-rebuild switch --flake .#nixos  # Применить и сохранить загрузку
```

Если flakes ещё не включены, добавьте к команде `--option experimental-features 'nix-command flakes'`.

## Обновление зависимостей

```bash
cd /etc/nixos
sudo nix flake update
sudo nixos-rebuild build --flake .#nixos
sudo nixos-rebuild switch --flake .#nixos
```

Сначала сохраните предыдущий `flake.lock`. Для отката:

```bash
sudo nixos-rebuild switch --rollback
```

## Пароль и SSH

```bash
passwd  # Пароль текущего пользователя
```

Не храните `initialPassword` открытым текстом в Nix-файлах. Если после переустановки изменился SSH-ключ, проверьте новый отпечаток на сервере и только затем удалите старую запись:

```bash
ssh-keygen -R 192.168.122.43
```
