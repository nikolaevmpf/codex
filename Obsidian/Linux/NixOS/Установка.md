# NixOS: установка UEFI с disko

[[Содержание|Главное оглавление]] · [[Linux/NixOS/Обзор|NixOS]]

Пример для x86_64 и **пустого диска `/dev/vda`**. Ветка NixOS — `26.05`. Имена диска и пользователя замените своими.

> [!warning] Разметка удалит данные
> Режим `disko` форматирует диск. Сначала проверьте `lsblk` и сделайте резервную копию.

## Live-система и SSH

```bash
ip address
lsblk -o NAME,SIZE,MODEL,MOUNTPOINTS
ls /sys/firmware/efi/efivars
passwd  # Пароль текущего live-пользователя nixos
sudo systemctl start sshd
```

С другого компьютера: `ssh nixos@АДРЕС`. Пароль live-системы не переносится в установленную систему.

## Flake

```bash
mkdir -p ~/nixos-config/hosts/nixos
cd ~/nixos-config
nano flake.nix
```

Содержимое `flake.nix`:

```nix
{
  description = "NixOS configuration";
  inputs = {
    nixpkgs.url = "github:NixOS/nixpkgs/nixos-26.05";
    disko = {
      url = "github:nix-community/disko";
      inputs.nixpkgs.follows = "nixpkgs";
    };
  };
  outputs = { nixpkgs, disko, ... }: {
    nixosConfigurations.nixos = nixpkgs.lib.nixosSystem {
      system = "x86_64-linux";
      modules = [
        ./hosts/nixos/configuration.nix
        ./disko.nix
        disko.nixosModules.disko
      ];
    };
  };
}
```

## Разметка

Создайте `disko.nix`:

```nix
{
  disko.devices.disk.main = {
    type = "disk";
    device = "/dev/vda"; # Проверить перед запуском
    content = {
      type = "gpt";
      partitions = {
        ESP = {
          size = "1G";
          type = "EF00";
          content = {
            type = "filesystem";
            format = "vfat";
            mountpoint = "/boot";
            mountOptions = [ "umask=0077" ];
          };
        };
        root = {
          size = "100%";
          content = {
            type = "filesystem";
            format = "ext4";
            mountpoint = "/";
          };
        };
      };
    };
  };
}
```

## Система

Создайте `hosts/nixos/configuration.nix`:

```nix
{ pkgs, ... }: {
  imports = [ ./hardware-configuration.nix ];
  system.stateVersion = "26.05"; # Версия первой установки; не менять при каждом обновлении
  nix.settings.experimental-features = [ "nix-command" "flakes" ];

  boot.loader.systemd-boot.enable = true;
  boot.loader.efi.canTouchEfiVariables = true;
  networking.hostName = "nixos";
  networking.networkmanager.enable = true;
  time.timeZone = "Europe/Moscow";
  i18n.defaultLocale = "ru_RU.UTF-8";
  console.keyMap = "ru";

  users.users.username = {
    isNormalUser = true;
    extraGroups = [ "wheel" "networkmanager" ];
    # Пароль задаётся после установки, а не хранится в Nix-файле
  };
  security.sudo.wheelNeedsPassword = true;
  environment.systemPackages = with pkgs; [ vim git curl wget htop ];
  services.openssh.enable = true;
  networking.firewall.allowedTCPPorts = [ 22 ];
}
```

## Установка

Из `~/nixos-config`, после проверки диска в `disko.nix`:

```bash
nix --extra-experimental-features 'nix-command flakes' flake lock
# Использовать ревизию disko из flake.lock
sudo nix --extra-experimental-features 'nix-command flakes' run \
  --inputs-from . disko -- --mode disko ./disko.nix

# Только аппаратная конфигурация: файловые системы уже описаны в disko
sudo nixos-generate-config --no-filesystems --root /mnt
sudo cp /mnt/etc/nixos/hardware-configuration.nix hosts/nixos/
sudo nixos-install --flake .#nixos

# Задать пароль своего пользователя; имя должно совпадать с конфигурацией
sudo nixos-enter --root /mnt -c 'passwd username'
# Сохранить весь проект и lockfile для дальнейшего управления
sudo cp -a . /mnt/etc/nixos/
sudo reboot
```

После перезагрузки: [[Linux/NixOS/Настройка|NixOS: изменение конфигурации]]. Для входа по SSH предпочтительнее ключи: [[Linux/Utility/ssh|SSH: ключи и сервер]].
