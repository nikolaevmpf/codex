## Базовая проверка

~~~bash
hostnamectl
nixos-version
uname -r
systemctl --failed
lsblk -f
findmnt -t btrfs -o TARGET,SOURCE,OPTIONS
findmnt /boot
df -h / /nix /home /var/tmp /boot
free -h
~~~

При ошибке смотреть журнал конкретной службы, а не сразу менять все настройки.

## Не хватает места при установке

~~~bash
df -h / /tmp /nix /nix/store
df -i / /tmp /nix
free -h
lsblk -o NAME,SIZE,TYPE,FSTYPE,MOUNTPOINTS
~~~

В нашем случае overlay /nix/store был около 2 ГиБ, свободно около 120 МиБ; корень live-системы — tmpfs. Большой целевой диск не расширяет overlay ISO.

Увеличить RAM VM и перезагрузить ISO; в прошлой попытке предлагалось 16 ГиБ. Проверить, увеличилось ли фактическое доступное место. Не запускать повторное форматирование без повторной проверки устройства.

## Ошибка сборки или загрузки пакета

~~~bash
cd ~/gnome-config
git status
nix flake show --flake "path:$PWD"
~~~

Сохранить первую содержательную ошибку и имя derivation. Проверить место и сеть. Не применять boot/switch после неуспешной сборки.

## UUID и дополнительные диски

~~~bash
lsblk -f
findmnt /boot
findmnt -t btrfs -o TARGET,SOURCE,OPTIONS
systemctl status games.automount games.mount --no-pager
~~~

Последняя команда относится к zet. Для NUC использовать mnt-Data.automount и mnt-Data.mount. Перед записью игр или VM активировать каталог через ls и проверить реальный источник через findmnt -T.

При переустановке обновить UUID в **своём** профиле. No such device после смены UUID не исправляется применением чужого профиля.

## NVIDIA и восстановление после сна

Для zet и 02i0132:

~~~bash
nvidia-smi
grep -E 'PreserveVideoMemoryAllocations|UseKernelSuspendNotifiers|TemporaryFilePath' /proc/driver/nvidia/params
systemctl status nvidia-suspend.service nvidia-resume.service --no-pager
df -h /var/tmp
nvidia-smi --query-gpu=memory.total --format=csv
~~~

В текущем коде включены stable, open=true, modesetting, powerManagement и сохранение видеопамяти в /var/tmp. Kernel suspend notifier выключен, используются systemd hooks.

Службы oneshot до первого сна могут быть inactive (dead). Это не достаточный признак ошибки. После изменения параметров перезагрузиться. Свободное место — не меньше VRAM с запасом; на 02i0132 около 12 ГиБ.

После сохранения работы проверить `systemctl suspend`. Если пришлось перезагрузиться принудительно:

~~~bash
sudo journalctl -b -1 -k --no-pager | grep -Ei 'NVRM|Xid|xhci|suspend|resume|PM:'
sudo journalctl -b -1 -u nvidia-suspend.service -u nvidia-resume.service --no-pager
~~~

Если система продолжает работать после resume, использовать -b вместо -b -1. Ранее на 02i0132 фиксировались Xid 13 и USB resume errors; окончательное исправление не подтверждено.

**Сон и гибернация различаются.** Zram помогает памяти, но не хранит образ RAM после выключения питания. Для гибернации нужны отдельный дисковый swap, resume и проверка на оборудовании; проект этого не содержит.

## GNOME не показывает новые настройки

~~~bash
echo "$XDG_SESSION_TYPE"
gnome-extensions list
gsettings get org.gnome.shell favorite-apps
journalctl -b -u display-manager --no-pager -n 80
~~~

У пользовательского dconf приоритет над defaults. [[Linux/NixOS/GNOME и приложения#Почему настройки не применились|Сброс отдельных ключей]]. При проблеме входа в GDM проверить журнал; не смешивать текущий GNOME с конфигурацией раннего niri.

## Сеть и SSH

~~~bash
nmcli device status
nmcli connection show
ip address
ip route
getent hosts github.com
systemctl status sshd --no-pager
~~~

NetworkManager управляет интерфейсами. Строки networking.hosts на zet/nuc только задают имена IP, а не статические адреса.

Общие настройки SSH: включён, root login запрещён, password authentication разрешена, порт открыт через services.openssh.openFirewall. Для GitHub нужны отдельные ключи и настройка клиента из README Obsidian.

## Firewall NixOS

Firewall включён в common.nix. UFW из общей Linux-памятки здесь не является способом управления текущей конфигурацией.

В своём модуле можно разрешить необходимый порт, объединяя список с существующими значениями:

~~~nix
networking.firewall.allowedTCPPorts = [ 22 443 ];
networking.firewall.allowedUDPPorts = [ 1194 ];
~~~

Это **пример**, не текущие дополнительные открытые порты проекта. Правила добавлять только для нужных служб.

~~~bash
systemctl status firewall --no-pager
journalctl -b -u firewall --no-pager
~~~

Для временной диагностики отказов можно включить networking.firewall.logRefusedConnections=true в конфигурации, собрать и смотреть kernel journal. После диагностики вернуть прежнее значение, если подробный журнал не нужен.

## MAX

~~~bash
journalctl -u install-max --no-pager -n 50
flatpak list --system
flatpak info --system ru.max.MAX
~~~

Проверить интернет, Flathub и свободное место. Первая загрузка может занимать несколько минут. Обновление MAX отдельно от обновления NixOS.
