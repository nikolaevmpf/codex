## 1. Получить конфигурацию

В установленной системе от nikolaev:

~~~bash
git clone https://github.com/nikolaevmpf/gnome-config.git ~/gnome-config
cd ~/gnome-config
~~~

Если каталог уже есть, вместо клонирования:

~~~bash
cd ~/gnome-config
git status
git pull --ff-only
~~~

HTTPS достаточно для чтения публичной конфигурации. Локальные изменения перед pull сохранить или разрешить вручную.

## 2. Выбрать профиль

| Машина | Профиль | Файл с UUID |
| --- | --- | --- |
| zet | zet | hosts/zet/default.nix |
| nuc | nuc | hosts/nuc/default.nix |
| 02i0132 | 02i0132 | hosts/02i0132/default.nix |
| VM, hostname nixos | vm | hosts/vm/default.nix |

`.#nixos` относится к установочному репозиторию, не к gnome-config. Dell в текущем flake не объявлен.

## 3. Сверить файловые системы

~~~bash
lsblk -f
findmnt -t btrfs -o TARGET,SOURCE,OPTIONS
findmnt /boot
lspci -nnk
~~~

Сверить UUID с паспортом своей машины. После переустановки заменить EFI UUID и Btrfs UUID своего профиля; системный Btrfs UUID повторяется для четырёх подтомов. Data и games проверить отдельно.

Не применять vm на физическом компьютере. До первого применения hostname может быть nixos, поэтому **не использовать автоматический выбор через nix-update**, а указать правильный профиль явно.

## 4. Создать lock-файл и собрать

В текущем gnome-config отслеживаемого flake.lock нет. Создать локальный файл:

~~~bash
cd ~/gnome-config
nix flake lock --flake "path:$PWD"
git status
~~~

Путь `path:` учитывает локальные файлы, включая неотслеживаемый lock-файл и изменения UUID. Выбрать одну строку:

| Машина | Проверить сборку | Подготовить следующую загрузку |
| --- | --- | --- |
| zet | `sudo nixos-rebuild build --flake "path:$PWD#zet"` | `sudo nixos-rebuild boot --flake "path:$PWD#zet"` |
| nuc | `sudo nixos-rebuild build --flake "path:$PWD#nuc"` | `sudo nixos-rebuild boot --flake "path:$PWD#nuc"` |
| 02i0132 | `sudo nixos-rebuild build --flake "path:$PWD#02i0132"` | `sudo nixos-rebuild boot --flake "path:$PWD#02i0132"` |
| VM | `sudo nixos-rebuild build --flake "path:$PWD#vm"` | `sudo nixos-rebuild boot --flake "path:$PWD#vm"` |

Команды рассчитаны на текущий каталог ~/gnome-config. К boot переходить только после успешного build. boot не переключает работающую систему.

~~~bash
sudo reboot
~~~

## 5. Проверить загрузку

~~~bash
hostname
nixos-version
systemctl --failed
systemctl status display-manager NetworkManager sshd --no-pager
findmnt -t btrfs -o TARGET,SOURCE,OPTIONS
findmnt /boot
~~~

Проверить GNOME, язык, звук, графику, сеть и дополнительные диски по паспорту компьютера. Предыдущее поколение сохранить до проверки. Затем доступна [[Linux/NixOS/Обновление и откат|команда nix-update]].

## Структура конфигурации

| Файл | Назначение |
| --- | --- |
| flake.nix | Четыре профиля и ветка nixpkgs |
| modules/common.nix | Пользователь, сеть, firewall, SSH, PipeWire, zram, очистка, nix-update |
| modules/gnome.nix | GNOME/GDM, Ghostty, Firefox, Dock, темы |
| modules/gaming.nix | Steam и GameMode физических машин |
| hosts/ИМЯ/default.nix | Hostname, загрузка, UUID и импорты |
| hosts/zet/nvidia.nix, hosts/02i0132/nvidia.nix | NVIDIA |
| hosts/nuc/hardware.nix | Intel/AMD и firmware NUC |
| hosts/ИМЯ/terminal.nix, ghostty.conf | Терминал физических машин |
| hosts/ИМЯ/virtualisation.nix | QEMU/KVM, libvirt |

Источник: [flake.nix](https://github.com/nikolaevmpf/gnome-config/blob/main/flake.nix).
