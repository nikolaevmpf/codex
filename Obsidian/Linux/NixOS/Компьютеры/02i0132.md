UUID взяты из текущего профиля; после переустановки могут измениться. Один Btrfs содержит @root → /, @home → /home, @nix → /nix, @log → /var/log. EFI монтируется в /boot.

## Установка и первое применение

При установке с нуля сначала [[Linux/NixOS/Установка|базовая установка]]. На установленной системе не запускать Disko.

Получить ~/gnome-config по [[Linux/NixOS/Применение профиля|общей инструкции]], сверить UUID и создать lock-файл. Затем:

~~~bash
cd ~/gnome-config
lsblk -f
findmnt -t btrfs -o TARGET,SOURCE,OPTIONS
findmnt /boot
sudo nixos-rebuild build --flake "path:$PWD#02i0132"
~~~

Только после успешной сборки:

~~~bash
sudo nixos-rebuild boot --flake "path:$PWD#02i0132"
sudo reboot
~~~

До первой загрузки профиля использовать именно 02i0132, даже если базовая система называется nixos.

## Проверки после перезагрузки

~~~bash
hostname
nixos-version
systemctl --failed
findmnt -t btrfs -o TARGET,SOURCE,OPTIONS
findmnt /boot
nvidia-smi
~~~


## Программы

В текущем default.nix: LibreOffice, Telegram, Obsidian, Pinta, Remmina, Zed, Transmission. Через общие модули также Firefox, Ghostty, Steam, GameMode. Amnezia включена отдельной опцией, MAX — через Flatpak.

В профиль включён Zed (`zed-editor`); запуск: `zeditor` или через меню GNOME. VS Code не включён.

Профиль не включает настройки MOZA и отдельный /games. Автовход в текущем профиле 02i0132 не объявлен.

## NVIDIA и сон

Монитор подключён к NVIDIA; PRIME не настроен. Драйвер stable, open=true, modesetting. Включены сохранение VRAM и systemd-службы suspend/resume, kernelSuspendNotifier=false, временное хранение /var/tmp.

Для 11 ГиБ VRAM оставлять около 12 ГиБ свободного места на файловой системе /var/tmp. После изменения параметров NVIDIA нужна перезагрузка.

Ранее отмечались NVRM Xid 13 и ошибки xhci_hcd при resume. Эти записи не доказывают, что текущая конфигурация уже исправила причину. Проверять только после сохранения работы. [[Linux/NixOS/Диагностика#NVIDIA и восстановление после сна|Диагностика сна]].

Гибернация отдельно не настроена.

## MAX и VPN

~~~bash
systemctl status install-max --no-pager
journalctl -u install-max --no-pager -n 50
flatpak run ru.max.MAX
systemctl status AmneziaVPN --no-pager
~~~

MAX требует интернета для первой установки и обновляется через Flatpak. После включения Flatpak при отсутствии значка выйти и войти в GNOME. В Amnezia импортировать свою конфигурацию; ключи VPN не хранить в репозитории.

## Терминал и виртуализация

Ghostty: JetBrains Mono 12, чёрный фон, окно 170 × 45, /etc/ghostty/02i0132.conf. KVM/libvirt, virt-manager, swtpm, virtiofsd и SPICE USB включены. После добавления групп выйти и войти снова или перезагрузиться.

## Obsidian и GitHub

Настройка GitHub Sync на этом компьютере завершилась успешно. Рабочая копия заметок — ~/obsidian, хранилище — ~/obsidian/Obsidian. Remote URL должен быть SSH и в Git, и в плагине. Полный порядок для второго компьютера находится в README репозитория Obsidian.


## Последующие изменения

~~~bash
nix-update
~~~

Для обновления пакетов:

~~~bash
nix-update --upgrade
~~~

Запускать от nikolaev, без sudo. После обновления ядра или драйвера перезагрузиться. Lock-файл и локальные правки сохранять осознанно: [[Linux/NixOS/Обновление и откат|подробности]].
