# Средства: личная памятка

> [!note] Не схема лечения
> Названия сохранены для справки. Показания, совместимость и дозировку проверяйте по инструкции и с врачом; препараты из одной строки не нужно принимать вместе.

## Лекарства

| Ситуация из заметки | Средства |
| --- | --- |
| Простуда | Инфлюнет |
| Герпес | Ацикловир |
| Заложенность носа | Тафен |
| Першение в горле | Фарингосепт |
| Аллергия | Кларитин, лоратадин, цетиризин, Лорагексал |
| Потливость | Жжёные квасцы, Формагель |
| Насморк | Риностоп |
| Грибковая инфекция | Нафтифин |

Кларитин и Лорагексал — торговые названия препаратов лоратадина.

## После алкоголя

- Вода, в том числе минеральная.
- Из прежней заметки: шипучий аспирин, Полисорб, активированный уголь.

Аспирин может раздражать желудок и повышать риск кровотечения после алкоголя; сорбенты не являются стандартным лечением похмелья. Старые универсальные дозировки убраны.

## Бытовые средства

- От комаров — Рефтамид.
- Для удаления запаха — OdorGone.
