## 1. Загрузиться в UEFI

Скачать [Minimal ISO x86_64](https://nixos.org/download/), записать на флешку и загрузиться в UEFI. Проверить:

~~~bash
test -d /sys/firmware/efi && echo "UEFI OK" || echo "Legacy BIOS"
ip address
lsblk -o NAME,SIZE,MODEL,TYPE,FSTYPE,MOUNTPOINTS
free -h
df -h / /tmp /nix /nix/store
~~~

Для этой конфигурации нужен UEFI; при Legacy перезагрузить ISO в правильном режиме.

## 2. Подключить сеть

Проводная сеть обычно получает DHCP. Для Wi-Fi:

~~~bash
nmcli device status
nmcli device wifi list
nmcli --ask device wifi connect "SSID"
ping -c 3 github.com
~~~

Пароль вводится в запросе. Если ping не отвечает, дополнительно проверить DNS и HTTPS.

Для установки по SSH в live-сеансе:

~~~bash
passwd
sudo systemctl start sshd
ip address
~~~

Подключиться с другого компьютера как `ssh nixos@АДРЕС`. Пароль live-сеанса не переносится в установленную систему.

## 3. Выбрать системный диск

~~~bash
sudo -i
lsblk -o NAME,SIZE,MODEL,SERIAL,TYPE,FSTYPE,MOUNTPOINTS
ls -l /dev/disk/by-id/
~~~

Дальше в live-системе команды выполняются от root. Нужен весь диск, не раздел. Имена sdX/nvmeX могут меняться; сверить модель, размер и серийный номер.

| Компьютер | Выбор |
| --- | --- |
| VM | В нашем примере Virtio-диск /dev/vda, около 100 ГиБ |
| zet | Проверить системный SSD, диск игр не форматировать |
| 02i0132 | Системный SSD 512 ГБ, сверить устройство |
| nuc | SSD около 232,9 ГиБ; Data около 931,5 ГиБ сохранить |
| Dell | Определить фактический диск; профиля пока нет |

## 4. Получить установщик

~~~bash
cd /tmp
nix --extra-experimental-features "nix-command flakes" shell nixpkgs#git -c \
  git clone https://github.com/nikolaevmpf/nixos_install.git
cd nixos_install
cat flake.nix
cat disko.nix
cat configuration.nix
nix --extra-experimental-features "nix-command flakes" flake lock
nix --extra-experimental-features "nix-command flakes" flake show
~~~

Ожидается `nixosConfigurations.nixos`. В disko.nix оставлен placeholder `/dev/disk/by-id/REPLACE_ME`: реальное устройство передаётся параметром `--disk main`. Обычное форматирование Disko с placeholder не запускать.

## 5. Установить систему

Ниже пример для VM. **Заменить /dev/vda проверенным системным диском своей машины.** Стабильный путь из /dev/disk/by-id также можно передать вместо него.

~~~bash
nix --extra-experimental-features "nix-command flakes" \
  run github:nix-community/disko/latest#disko-install -- \
  --write-efi-boot-entries \
  --flake .#nixos \
  --disk main /dev/vda
~~~

Это способ из текущего README установщика. `latest` и локально создаваемый lock-файл могут разрешаться в новые ревизии; для повторяемой установки сохранить использованный flake.lock и ревизию Disko.

## 6. Разметка и базовые службы

| Файловая система | Подтом / размер | Монтирование |
| --- | --- | --- |
| EFI FAT32 | 1 ГиБ | /boot |
| Btrfs на остатке диска | @root | / |
| Та же Btrfs | @home | /home |
| Та же Btrfs | @nix | /nix |
| Та же Btrfs | @log | /var/log |

На Btrfs включено compress=zstd; для / и /nix также noatime. Подтома используют общее свободное место. Снимки автоматически не настроены. Swap-раздела нет, включён zram; гибернация не настроена.

База содержит systemd-boot, NetworkManager, SSH, пользователя nikolaev, русский язык и Europe/Moscow.

## 7. Первый вход и проверка

После успешного завершения установки выполнить `reboot` и извлечь ISO/флешку. В текущем шаблоне временный пароль nikolaev — `nixos`; сразу сменить:

~~~bash
passwd
nixos-version
hostnamectl
lsblk -f
findmnt -t btrfs -o TARGET,SOURCE,OPTIONS
findmnt /boot
systemctl status NetworkManager sshd --no-pager
~~~

После форматирования UUID меняются. Исправить их в рабочем профиле до применения GNOME.

Репозиторий из /tmp live-системы не становится автоматически /etc/nixos. Постоянное управление проектом — через `~/gnome-config` и явный профиль: [[Nix/Применение профиля|следующий этап]].

## Ошибка места в live-системе

Ранее VM имела 4 ГиБ RAM, overlay /nix/store — около 2 ГиБ. Установка остановилась с No space left on device ещё до разметки. Свободное место целевого диска эту проблему не решало.

См. [[Nix/Диагностика#Не хватает места при установке|проверки live-окружения]]. Увеличить RAM VM, например до 16 ГиБ, и проверить фактическое место после новой загрузки ISO.
