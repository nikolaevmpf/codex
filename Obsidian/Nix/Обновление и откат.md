## Одна команда

После первого применения профиля:

~~~bash
nix-update
~~~

Запускать от обычного пользователя **без sudo**, из любого каталога. Команда использует ~/gnome-config, получает git pull --ff-only и выполняет nixos-rebuild switch. Пароль sudo запрашивается при применении.

| Hostname | Выбранный профиль |
| --- | --- |
| zet | zet |
| nuc | nuc |
| 02i0132 | 02i0132 |
| nixos | vm |

Выбор имени встроен в сгенерированный скрипт при сборке конфигурации. Базовую установку с hostname nixos сначала переводить на правильный профиль явно.

Скрипт блокирует параллельные обновления через flock, останавливается при ошибке Git или сборки, не удаляет и не прячет локальные правки. Отдельного шага build перед switch в скрипте нет: switch сам собирает и применяет.

## Обновить версии пакетов

~~~bash
nix-update --upgrade
~~~

Дополнительно обновляет локальный flake.lock в пределах nixos-26.05. Lock-файл не коммитится и не отправляется автоматически. Путь path: включает локальный lock и изменения.

Обычный nix-update с существующим lock не является обновлением всех пакетов: версии фиксируются lock-файлом, пока тот не изменён. Новое поколение после обновления ядра/драйвера проверить перезагрузкой. MAX обновлять отдельно через Flatpak.

## Сборка вручную

Пример **для zet**; на другом компьютере заменить профиль:

~~~bash
cd ~/gnome-config
git status
git pull --ff-only
sudo nixos-rebuild build --flake "path:$PWD#zet"
~~~

После успешного build выбрать нужное действие:

| Действие | Команда | Результат |
| --- | --- | --- |
| Проверка активации | `sudo nixos-rebuild test --flake "path:$PWD#zet"` | Применяется сейчас без изменения загрузки по умолчанию |
| Следующая загрузка | `sudo nixos-rebuild boot --flake "path:$PWD#zet"` | Записывает поколение, не переключает текущую систему |
| Постоянное применение | `sudo nixos-rebuild switch --flake "path:$PWD#zet"` | Применяет сейчас и обновляет загрузку |

## Локальные изменения и lock-файл

~~~bash
cd ~/gnome-config
git status
git diff
git diff -- flake.lock
~~~

Не удалять flake.lock только ради успешного pull: это меняет набор версий. Сохранить нужные изменения отдельным коммитом или копией и разрешить конфликт вручную. Автоматический stash скриптом не делается.

Для воспроизводимости нескольких компьютеров использовать согласованный отслеживаемый lock-файл. Сейчас в удалённом gnome-config его нет, поэтому первый запуск на разных компьютерах в разные дни может дать разные версии. Это состояние проекта, не гарантия одинаковых пакетов.

## Откат

Если работающий сеанс доступен:

~~~bash
sudo nixos-rebuild switch --rollback
~~~

Если новая система не загрузилась или нет графики, выбрать предыдущее поколение NixOS в меню systemd-boot. После входа исправить конфигурацию и только затем повторить сборку.

Откат поколения не возвращает файлы в Git, flake.lock, документы в /home или базы приложений. При необходимости восстановить также исходную конфигурацию и lock-файл.

## Автоматическая очистка

| Настройка | В проекте |
| --- | --- |
| Nix garbage collection | Еженедельно, --delete-older-than 30d |
| Оптимизация store | Еженедельно |
| systemd journal | SystemMaxUse=500M |
| systemd-boot | До 10 записей в профилях |
| Данные /home, игры | Очисткой Nix не удаляются |

Удаление старых поколений уменьшает доступную историю отката. Не запускать агрессивную очистку до проверки нового поколения. Ограничение записей bootloader и сборка мусора — разные механизмы.

~~~bash
systemctl list-timers --all | grep -E 'nix-gc|nix-optimise'
journalctl -u nix-gc.service --no-pager -n 50
df -h / /nix /home /boot
~~~

## Добавление программы

Изменить environment.systemPackages в модуле своего профиля, объединяя с существующим списком. Общие программы всех машин добавлять в common.nix, GNOME — в gnome.nix.

Пример фрагмента, не отдельный второй блок:

~~~nix
environment.systemPackages = with pkgs; [
  git
  obsidian
];
~~~

После редактирования собрать правильный профиль. При path: учитываются локальные файлы; для сохранения в репозитории их отдельно добавить и закоммитить.

Источник: [modules/common.nix](https://github.com/nikolaevmpf/gnome-config/blob/main/modules/common.nix).
