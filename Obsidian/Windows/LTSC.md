# Windows 11 IoT Enterprise LTSC 2024

## Образ и лицензия

Используйте официальный канал загрузки, соответствующий своей лицензии. [Archive.org](https://archive.org/) из прежней заметки — сторонний архив, не источник лицензии; происхождение и контрольную сумму образа проверяйте отдельно.

## После установки

- Установить обновления и драйверы.
- Проверить активацию: [[Activation]].
- При необходимости отключить индексацию: **Свойства диска → Разрешить индексировать содержимое файлов…**. Поиск может стать медленнее.

## Microsoft Defender

Ссылка из прежней заметки: [Windows Defender Remover](https://github.com/ionuttbara/windows-defender-remover).

Удаление защиты не включено в базовую настройку. Для ложных срабатываний лучше проверить файл и настроить точечное исключение, если ему доверяете.
