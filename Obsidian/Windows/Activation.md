# Windows: активация и локальная учётная запись

[[Содержание|Главное оглавление]] · [[Windows/Обзор|Windows]]

## Активация

Для своей лицензии: **Параметры → Система → Активация → Изменить ключ продукта**. На корпоративном компьютере используйте способ, предоставленный администратором.

### Сторонний скрипт из прежней заметки

Источник: [get.activated.win](https://get.activated.win). Вместо немедленного `irm ... | iex` сначала сохраните и прочитайте файл:

```powershell
Invoke-WebRequest -Uri 'https://get.activated.win' -OutFile "$env:TEMP\activation-script.txt"
notepad "$env:TEMP\activation-script.txt"
```

Скачивание не запускает скрипт и не предоставляет лицензию. Применимость и доверие к источнику проверяйте отдельно.

## Локальная учётная запись при установке

На экране входа в Microsoft нажмите **Shift + F10**. В командной строке:

```cmd
start ms-cxh:localonly
```

Метод зависит от сборки Windows и может быть недоступен. Если откроется окно создания пользователя, укажите имя и пароль.
